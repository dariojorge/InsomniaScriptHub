# About

When having to use a lot of endpoints, not always can be possible to quickly adapt those for a faster debug, monitoring or for operations, and to adapt the request bodies can waste a lot of time.
For this plugin the obective is to be able to make requests faster with a fast adaption of the settings, there is also a chain request option, this allows to have a chain request based on the target endpoint to have data show from all the calls.
